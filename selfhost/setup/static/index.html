StackChan 配置

输入这台服务器的 ADMIN_TOKEN。它在 selfhost/data/setup-admin.token，首次启动时也会打印在控制台。

StackChan 服务端配置

写 deploy.env → render → 重启容器；失败自动回滚。
dry-run：只写文件，不重启

连接

DEVICE_HOST 是设备能访问到的局域网地址；PUBLIC_BASE_URL 是手机能访问到的地址（Tailscale HTTPS 或 LAN）。

LLM

只支持 OpenAI Chat Completions 兼容端点（URL 必须以 /chat/completions 结尾）； Responses / Anthropic Messages / Gemini 需要另加 provider 适配。

Model 填供应商文档里的模型 ID（不是显示名）。DeepSeek 当前官方 ID 是 deepseek-flash / deepseek-v4-pro；deepseek-chat 是旧别名。

天气（可选）

建议注册和风天气（免费开发版）： console.qweather.com。 在控制台创建项目后，填它给的 API Host 和 Key；没有 key 就留空，插件会返回不可用，不影响对话。

时区

默认按服务器系统时区自动识别；可直接下拉改。保存时 TZ_OFFSET 自动推导。

记忆功能

默认关闭。开启后会在 data/memory.json 记录对话摘要，供后续会话参考。

人设

写进 templates/persona.txt，保存后 render 到 prompt:。
